## About

I build focused software for English-speaking clients worldwide through a registered Polish business.

My work is centred around four practical service areas:

- **Professional websites** — responsive landing pages, portfolios, and business sites
- **Web applications** — authentication, dashboards, databases, APIs, and deployed products
- **Windows .NET tools** — C#, WinForms, local utilities, integrations, and workflow automation
- **Roblox systems** — modular Luau, persistent data, UI logic, and server-side validation

I prefer clearly scoped projects, direct communication, maintainable code, and deliverables that can be tested against an agreed result.
